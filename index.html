규칙관리

프로그램이 현재 자동으로 적용하는 거래처·품목·VAT·신상마켓 매칭을 한곳에서 확인합니다. 기준정보 자동연결까지 포함한 전체 적용규칙을 볼 수 있고, 사용자 규칙은 직접 추가·수정·삭제할 수 있습니다. 기준정보 규칙을 삭제하면 원본 기준정보 자체를 지우지 않고 자동연결 제외규칙으로 저장해 안전하게 막습니다.

거래처 매칭 규칙
최신 거래처 기준정보의 거래처명·장끼거래처명 → 거래처코드 자동연결과 Firebase 사용자 매칭을 모두 보여줍니다. 사용자 규칙이 있으면 기준정보보다 우선합니다.
원본 거래처명과 연결할 거래처를 입력하면 수기 규칙을 추가할 수 있습니다.
품목 매칭 규칙
품목 기준정보의 품목명 → 품목코드 자동연결과 Firebase 품목 매칭을 모두 보여줍니다. 수기로 새 규칙을 추가하거나 기존 규칙을 다른 코드로 수정할 수 있습니다.
원본 품목명과 연결할 품목을 입력하면 수기 규칙을 추가할 수 있습니다.
VAT 거래처 규칙 · 1.1 계산
현재규칙 보기 버튼 없이 전체 규칙이 아래 목록에 바로 표시됩니다. Firebase 사용자규칙 → 기존 학습규칙 → 신상마켓 기본규칙 순으로 적용합니다. 기존 규칙을 수정하면 사용자규칙으로 덮어쓰며, 기존 규칙을 삭제하면 자동적용 제외로 저장할 수 있습니다.
거래처를 입력하면 사용자 VAT 규칙을 추가할 수 있습니다.

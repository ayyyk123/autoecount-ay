VAT 검수 필요 장끼

부가세 확인이 필요한 장끼입니다. 매장은 부가세행이 없고 아직 학습/저장된 규칙이 없을 때 확인하며, 창고는 부가세행이 없으면 입력누락 여부를 놓치지 않도록 항상 확인합니다. 매장은 포함이면 단가÷1.1, 별도면 단가 그대로이고, 창고는 단가를 수정하지 않습니다. 확인이 끝나기 전에는 완료본이 잠깁니다.

매칭/파일 검수

Firebase에는 품목 기준정보, 수동 품목매칭, 거래처별 VAT 규칙을 저장합니다. 거래처리스트는 Firebase에 저장하지 않고 매 실행 최신 파일을 직접 사용합니다. 기존 학습 VAT 규칙도 자동변환에 사용하되, 이번 변환에서 자동 적용된 장끼는 별도 목록으로 보여줍니다. 검수 중인 판매내역/일별정산 원본과 작업 진행상태는 여러 PC에서 이어서 작업할 수 있도록 Firebase Firestore에 분할 저장합니다. 이 PC 브라우저에도 임시 캐시를 유지합니다.
